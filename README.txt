推奨調整版

上書き:
  webui.py
  raglib\search_engine.py

追加:
- 検索モード: 自動 / 厳密 / バランス / 発見重視
- 最優先記事と補助資料を明確に分離
- 最優先記事へ参考資料予算の75%を配分
- 別人物・別作品の混同、根拠のない数値・固有名詞の補完を抑制
- URLを生成モデルに書かせない
- done_reason表示
- 既定値: 5000文字 / num_ctx 4096 / num_predict 2048

推奨:
  通常は「自動」
  記事を正確に読む場合は「厳密」
  関連記事も使う場合は「バランス」
  独立記事がない対象は「発見重視」

インデックス再構築は不要です。
