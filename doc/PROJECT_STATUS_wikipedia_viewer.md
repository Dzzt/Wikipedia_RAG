# PROJECT_STATUS.md

## プロジェクト名

Wikipedia JSONL Viewer

---

# 目的

ローカルRAGシステムからWikipedia記事全体を閲覧するための専用ビューアを作成する。

RAGはチャンク単位で検索・回答を行うが、必要に応じて元記事全体を高速に閲覧できるようにすることが目的。

MediaWiki互換を目指すものではなく、RAG用JSONLから記事を表示することだけを目的とする。

---

# 背景

Wikipedia XMLダンプから独自スクリプトでJSONLを生成している。

JSONLは

```json
{
    "text": "...本文...",
    "meta": {
        "title": "...",
        ...
    }
}
```

という形式。

現在はJSONLをSQLiteへ変換し、

title
→ article

で高速検索して表示する。

---

# 設計方針

役割を完全に分離する。

RAG
    ↓
検索・回答

Viewer
    ↓
記事閲覧

Viewerは検索を行わない。

ViewerはSQLiteから記事を表示するだけ。

---

# 現在の呼び出し方法

RAG(WebUI)から

```python
subprocess.Popen([
    "py",
    str(VIEWER_SCRIPT),
    "--db",
    str(VIEWER_DB),
    "--title",
    title,
])
```

で起動する。

Viewerは

--db
--title

だけ受け取ればよい。

---

# Python

ViewerはPython 3.14。

Wikipedia XML→JSONL変換だけは
mwparserfromhell未対応のため
Python 3.13を使用。

Viewer側は標準ライブラリのみで構成する。

---

# 不要になった機能

以下は不要。

・SQLite選択
・JSONL選択
・索引作成ボタン
・build-index
・source指定

Viewerは完成済みSQLiteのみ扱う。

# 単一インスタンス

Viewerは1つだけ起動する。

同じSQLiteを使うViewerが既に存在する場合は、

新しいプロセスは起動せず

既存Viewerへ

title

だけ送る。

---

# タブ動作

外部からtitleが送られるたび

新しいタブを開く。

既存タブは残す。

タブ切替可能。

---

# 閉じる動作

各タブに

×

を付ける。

×

でそのタブだけ閉じる。

最後のタブを閉じたら

Viewer全体を終了する。
