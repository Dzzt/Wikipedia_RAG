# Wikipedia RAG 検索アルゴリズム設計書

## 1. 目的

本資料は、現時点の `search_engine_default.py` および `webui_default.py`
を中心とした検索アルゴリズムの設計をまとめたものである。

## 2. システム構成

    質問
      │
      ▼
    SearchEngine
      │
      ├─ 質問Embedding（ruri）
      ├─ FAISS検索
      ├─ タイトル一致判定
      ├─ 記事内再検索（auto）
      ├─ スコアリング
      └─ Result生成
              │
              ▼
    webui
              │
              ▼
    コンテキスト生成
              │
              ▼
    Ollama

## 3. インデックス

-   チャンク単位
-   Embedding: ruri
-   FAISS IVF+PQ
-   SQLiteにメタデータ・float16ベクトル保存

## 4. 検索モード

### auto（標準）

1.  質問から記事タイトル候補を判定
2.  タイトル確定時は記事内検索へ
3.  失敗時は従来検索へフォールバック

### strict

タイトル一致を重視。

### balanced

従来のバランス検索。

### discovery

幅広い候補を返す。

## 5. autoの詳細

    質問
     ↓
    記事タイトル特定
     ↓
    成功？
     ├─Yes
     │   ↓
     │ タイトル除去
     │ 依頼表現除去
     │
     │ 記事内クエリ
     │
     │ 記事内全チャンク再順位付け
     │
     └─No
         ↓
     従来検索

### 記事内クエリ例

  ------------------------------------------------------------------------------------------------------
  質問                                               記事                        記事内クエリ
  -------------------------------------------------- --------------------------- -----------------------
  ロサンゼルス・ドジャースの大谷翔平について教えて   ロサンゼルス・ドジャース    大谷翔平

  ファイナルファンタジーXIVの漆黒のヴィランズ        ファイナルファンタジーXIV   漆黒のヴィランズ
  ------------------------------------------------------------------------------------------------------

## 6. スコアリング

-   FAISS候補
-   float16ベクトルで再計算
-   タイトル一致ボーナス
-   （記事内検索では）本文一致も補助利用

## 7. コンテキスト生成

検索結果を記事ごとにまとめる。

-   最優先記事：約75%
-   補助記事：約25%

チャンクは記事内順に並べてLLMへ渡す。

## 8. 今回の改善

旧方式ではタイトル語がEmbeddingに強く影響し、記事内の細かな話題が埋もれやすかった。

新方式では記事特定後に記事内検索を行うことで、

-   記事内検索精度向上
-   コンテキスト短縮
-   LLM入力トークン削減
-   応答速度向上

を実現した。

## 9. 今後の改善候補

-   記事内FTS
-   前後チャンク自動展開
-   lexical score改善
-   RRF導入検討
-   コンテキスト切り詰め改善

## 10. 設計方針

「Wikipedia全体検索」と「記事内検索」を分離し、それぞれの役割を明確にする。
