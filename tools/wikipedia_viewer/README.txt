Place the following existing Wikipedia viewer files in this directory:

- wikipedia_articles.sqlite3
- wikipedia_jsonl_viewer.cmd
- wikipedia_jsonl_viewer.py
- wikipedia_jsonl_viewer_buildindex.ps1

The JSONL viewer is the default article viewer.
The application validates the .cmd, .py, and .sqlite3 files at startup.
The PowerShell script is retained here for rebuilding the viewer index when needed.
